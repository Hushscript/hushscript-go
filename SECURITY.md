# Security policy

## Reporting a vulnerability

Please report security problems privately. Use GitHub's "Report a vulnerability" button on the
Security tab of this repository, or email support@hushscript.com. Please do not open a public issue.

We acknowledge reports within three working days. This repository holds client code and test
fixtures; it holds no customer data and no production credentials. If you find a real token, key or
personal data in the history, tell us so we can rotate it.

## Supported versions

Only the latest release is supported.
